# CEC Educational Consult

> **Premier Preschool & Early Childhood Education Consultancy, Teacher Recruitment Network, CEC Spaces, and Learning Essentials in Ghana & across Africa.**

Founded by Early Childhood Specialist **Miss Nancie**, **CEC Educational Consult** bridges the gap between high-caliber early childhood educators and progressive schools, while empowering educational institutions with world-class curriculum frameworks, classroom architectural setup, literacy clubs, and hands-on professional workshops.

---

## 🌟 Core Pillars & Key Features

### 1. 🎓 Vetted Teacher Recruitment Network
- **Exclusive Talent Directory**: Search, filter, and discover vetted preschool and early childhood educators by curriculum (EYFS, Montessori, Reggio Emilia, Cambridge Primary), experience level, and certifications.
- **Detailed Teacher Profiles**: View video bios, teaching philosophies, verified credentials, specialties (phonics, sensory play, STEM, special needs), and direct interview booking requests.
- **Teacher Onboarding & Applications**: Streamlined onboarding flow for certified teachers to join the network, upload CVs/certificates, and manage profile visibility.

### 2. 🏛️ Educational Consultancy & School Audits
- **Curriculum Implementation & Audits**: Comprehensive reviews of EYFS, Montessori, and British/Ghanaian hybrid curricula.
- **School Health & Safety Audits**: Assessment of early years learning environments, compliance, and child safety standards.
- **Tailored Consultation Bookings**: Live scheduling for in-person school visits across Accra or virtual strategy sessions.

### 3. 🎨 CEC Spaces — Classroom Design & Renovation
- **Preschool Architecture & Transformation**: Custom classroom setups, Montessori floor layouts, outdoor sensory play areas, and child-safe ergonomic furniture.
- **Project Gallery & Case Studies**: Showcase of before-and-after school renovations, toddler sensory studios, and vibrant play stations.
- **Custom Space Quotations**: Interactive design consultation requests and floor plan estimates.

### 4. 📚 The Reading Lounge & Phonics Club
- **Early Literacy & Phonics Mastery**: Fun, phonics-grounded weekend and after-school reading clubs for children ages 2–8.
- **Sensory Storytelling & Play**: Multi-sensory learning sessions, interactive phonemic awareness games, and take-home book packages.
- **Parent & Child Enrolment**: Direct student registration and term batch bookings.

### 5. 🛠️ Professional Development & Certified Workshops
- **Practical Educator Workshops**: Hands-on masterclasses covering EYFS phonics, positive behavioral management, sensory play design, and classroom leadership.
- **Seat Reservations & Certificate Verification**: Seamless online workshop ticket registration and digital proof of attendance.

### 6. 🛍️ CEC Learning Essentials
- **Curated Educational Resources**: Specialized Montessori wooden sensorial materials, decodable phonics card sets, curriculum planning guides, and fine-motor manipulative toolkits.
- **Quick-View Product Details & Ordering**: Interactive catalog with instant WhatsApp order integration.

### 7. 🔐 Multi-Role Portals
- **Teacher Portal**: Dashboard for registered educators to track job placement status, manage profile information, log professional development, and receive school interview invites.
- **School Admin Portal**: Comprehensive command center for proprietors to review candidate submissions, manage consultation appointments, approve teacher profiles, and log school setup requests.

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Lucide React Icons, Motion animations
- **Audio/Video**: HTML5 Video Streaming pipeline with adaptive Cloudinary media delivery
- **Data Persistence**: Local-first state engine with real-time in-memory synchronizers and modular schema models

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Install dependencies
npm install

# Launch development server
npm run dev
```

### Production Build
```bash
# Compile and optimize production bundle
npm run build
```
